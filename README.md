# Next-Word_predictor
# 🧠 Deep Learning Next Word Prediction

A Deep Learning-based **Next Word Prediction** system built using **PyTorch** and **Long Short-Term Memory (LSTM)** networks. The model learns contextual relationships from text sequences and predicts the most probable next word given an input phrase, demonstrating the fundamentals of neural language modeling.

---

## 🚀 Overview

This project implements an end-to-end Natural Language Processing (NLP) pipeline for next-word prediction. It includes text preprocessing, vocabulary generation, sequence creation, model training, and inference using an LSTM-based architecture.

The objective is to understand how recurrent neural networks capture sequential dependencies in text and generate context-aware predictions.

---

## ✨ Features

- Deep Learning-based language modeling using LSTM
- Text preprocessing and tokenization
- Vocabulary construction and indexing
- Sequence generation for supervised learning
- Word Embedding layer for dense vector representations
- Custom PyTorch Dataset and DataLoader
- Model training with CrossEntropy Loss and Adam Optimizer
- Context-aware next-word prediction
- Easily adaptable to custom text datasets
